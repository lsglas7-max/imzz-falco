IMZYY XL Lite (ARM64)

1. Push this project to the ROOT of your GitHub repo (the folders .github, scripts, android-overlay must be at the root).
2. Actions > "Build IMZYY XL LITE (ARM64)" runs on every push to main (or press Run workflow).
3. When it is green:
   - Download the artifact "IMZYY-XL-Lite-ARM64-debug" (zip containing the APK).
   - A pre-release named "Java runtimes (auto)" (tag: runtimes) is created. Do NOT delete it: the app downloads Java 8/17/25 from it.
4. The run summary shows "APK size".
The full (big) build is manual only: Actions > "Build IMZYY XL Launcher (ARM64)" > Run workflow.

5. The LUNA AI tab (Luna Sixty) is included in the launcher. Its diagnostic upload runs only after the user taps the analysis button.
